# ED Git Website - Jamones S.L.

## Descripción
Este repositorio contiene el código fuente para el sitio web corporativo de Jamones S.L., una empresa dedicada a el desarrollo de patas de jamón de una manera sostenible. El objetivo de este proyecto es presentar la compañía, sus servicios y su identidad visual a través de una página web moderna y accesible.

## Tecnologías Utilizadas
El proyecto ha sido desarrollado empleando las tecnologías web básicas y estándar:
* **HTML5**: Para la estructuración y el contenido semántico de las páginas web.
* **CSS3**: Para el diseño, la maquetación y el estilo visual del sitio.
